# ORBIT Product Vision

## Product statement

ORBIT is an intelligent, adaptive, secure desktop operating system designed to make computing feel effortless without hiding the power users need.

**Tagline:** Computing, without friction.

## Audience

A broad desktop audience that wants a modern and comfortable computing experience, including everyday users, creators, developers and professionals.

## Product principles

1. **Performance:** responsiveness is a product feature; avoid unnecessary background work and measure real workloads.
2. **Simplicity:** make core tasks easy to discover and complete.
3. **Reliability:** use recoverable updates, diagnostics and clear recovery paths.
4. **Security:** least privilege, isolation, transparent permissions and verified software.
5. **Compatibility:** support hardware and existing applications through established standards and compatibility layers.

## Differentiating experience

- **ORBIT Spaces:** user-defined work contexts with app and window layouts.
- **ORBIT Command:** a universal keyboard-first command/search surface.
- **Adaptive Control Center:** one coherent place for settings, devices and privacy.
- **ORBIT Restore:** recoverable system updates and guided recovery.
- **ORBIT Intelligence:** optional, permission-controlled AI assistance with local-first defaults.
- **ORBIT Guard:** understandable app permissions and isolation.

## Non-goals for Alpha 0.1

- Replacing the Linux kernel.
- Shipping a public installer.
- Guaranteeing Windows or macOS application compatibility.
- Running privileged system actions from the UI.
- Uploading user files or telemetry to a cloud service.

## Alpha 0.1 user promise

A user can launch the ORBIT desktop preview, navigate its overview, inspect the proposed workspace model, open the command palette and explore the quick-settings concept. UI-only actions are clearly identified as previews until system services exist.
